# SentinelAI — LinkedIn Showcase Post

---

🛡️ **Introducing SentinelAI — My Graduation Project**

After months of intensive development, I'm proud to present **SentinelAI**: a fully autonomous, AI-powered Security Operations Center platform built from scratch.

This isn't a tutorial clone or a simple script — it's a **production-grade enterprise system** designed to replace manual SOC operations with intelligent automation.

---

🔍 **What it does:**

✅ Collects logs from Linux, Windows, network devices & cloud (AWS/Azure/GCP)
✅ Detects threats using **12 custom Sigma rules** + YARA + Suricata IDS
✅ **Correlates multi-stage attack chains** automatically (Brute Force → Privesc → Reverse Shell)
✅ AI anomaly detection with **Isolation Forest + XGBoost ensemble**
✅ **LangChain + Ollama LLM** explains every alert in plain English
✅ Automated incident response with **6 SOAR playbooks** (phishing, ransomware, DDoS, exfil...)
✅ Threat intelligence enrichment from VirusTotal, AbuseIPDB, AlienVault OTX
✅ **Honeypot traps** (SSH/FTP/HTTP) with real-time attacker fingerprinting
✅ Malware sandbox with YARA scanning + behavioral analysis
✅ **Impossible travel detection** on VPN connections
✅ CIS Benchmark cloud posture scanning (AWS/Azure)
✅ Full MITRE ATT&CK mapping on every alert
✅ AI Red Team Simulator for validating detection coverage
✅ **Multi-Agent AI Architecture** — 6 specialized agents working in parallel

---

⚙️ **Tech Stack:**

🐍 Python (FastAPI, scikit-learn, XGBoost, LangChain)
⚛️ React + Next.js dashboard with real-time WebSocket alerts
Kubernetes (HPA auto-scaling)
📨 Apache Kafka message queue
🔍 OpenSearch for log indexing (50k events/sec target)
🗄️ PostgreSQL + Redis
🤖 Ollama (local LLM — llama3.2)
🔐 JWT + TOTP MFA + RBAC
☁️ Terraform IaC for AWS deployment (EKS + RDS + MSK + OpenSearch)

---

📊 **Architecture:**

14 microservices, each independently deployable and scalable:
`auth → log-ingestion → kafka → detection-engine → ai-engine → soar → alerts → dashboard`
